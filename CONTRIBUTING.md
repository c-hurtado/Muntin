# Contributing to FanciestZones

Thanks for your interest. FanciestZones is small and personal, so please open an issue to talk about a change before you send a pull request.

- The FanciestZones code is in [`src/modules/fancyzones`](src/modules/fancyzones). The rest of the repository is the PowerToys code base it builds on; changes there are better sent to [PowerToys](https://github.com/microsoft/PowerToys).
- Build and test as described in the [guide](FanciestZones.md#rebuild-it). Add a unit test in `src/modules/fancyzones/FancyZonesTests/UnitTests/DockTree.Spec.cpp` for a change in docking behavior.
- Keep [FanciestZones.md](FanciestZones.md) in step with any change you make to behavior or settings.

By sending a contribution, you agree that it is released under the [MIT License](LICENSE) of this repository.
