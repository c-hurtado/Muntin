# Security

FanciestZones is a personal open-source project, not a Microsoft product.

To report a security problem in FanciestZones, use [private vulnerability reporting](https://github.com/c-hurtado/FanciestZones/security/advisories/new) on GitHub. Please don't open a public issue for it.

If the problem is in PowerToys code that FanciestZones shares with the upstream project, report it to Microsoft as described in the [PowerToys security policy](https://github.com/microsoft/PowerToys/blob/main/SECURITY.md).
